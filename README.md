# MotoLog 🏍️

O **MotoLog** é uma aplicação web desenvolvida para auxiliar entregadores autônomos (motoboys) no controle financeiro e gerenciamento de suas corridas diárias.

## 🚀 Sobre o Projeto
O projeto nasceu da necessidade real de um entregador que tinha dificuldades em acompanhar seus ganhos e se perdia com os valores recebidos ao longo do dia. O MotoLog centraliza essas informações de forma simples e acessível.

## 🛠️ Funcionalidades
* **Registro de Entregas:** Histórico detalhado de cada corrida realizada.
* **Faturamento Diário:** Cálculo automático do valor total faturado no dia.
* **Métricas Financeiras:** Cálculo da média de ganho por entrega para ajudar no planejamento de metas.
* Outras opções de gerenciamento interno.

## 💻 Tecnologias Utilizadas
* **HTML5** (Estruturação)
* **CSS3** (Estilização e Responsividade)
* **JavaScript (ES6+)** (Lógica de negócios e cálculos)
